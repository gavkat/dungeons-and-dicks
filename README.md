# Dungeons & Dicks — Campaign Vault

An [Obsidian](https://obsidian.md) vault chronicling two D&D campaigns set in the **same world** on the Sword Coast:

1. **[Lost Mine of Phandelver](Campaign%201/Lost%20Mine%20of%20Phandelver.md)** (Campaign 1) — the saga of the **Wolfpack**, who defeated the Black Spider and reignited the Forge of Spells, lighting the new industrial age.
2. **[Echoes of Phandelver](Campaign%202/Echoes%20of%20Phandelver.md)** (Campaign 2) — five years later, that new age hides a darker undercurrent as the **Dark Six** return.

Characters, places, and powers that span both campaigns live in **[Shared/](#shared-across-both-campaigns)** so each is a single page.

### Folder layout

```
Campaign 1/          Lost Mine of Phandelver — hub page + the folders below
Campaign 2/          Echoes of Phandelver — hub page, Open Threads + the folders below
  Sessions/          one page per session
  Party/             player characters (and Campaign 2's party page, Boner Bros)
  NPCs/              non-player characters
  Places/            locations
  Factions/          factions and organizations
  Items/             items and weapons
  Lore/              lore, mechanics, deities and powers
Shared/              anything that appears in both campaigns
```
